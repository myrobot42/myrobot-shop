🔧 DATA CLEANUP — Detect and fix data quality issues
Scans your entire database for common corruption patterns. Each issue type can be reviewed individually with side-by-side previews before applying. Nothing is committed until you click 💾 Save Cleanup.
Reviewing issues
🎯 DUPLICATE HUNTER — find robots listed twice under different names
Fuzzy-matches robot model names within each brand. Matches ≥85% confidence are auto-merged silently: older record keeps its ID/slug (SEO-safe), all non-empty fields merge in, images combine. Lower-confidence pairs are flagged below for manual review. Field conflicts (where both records have different non-empty values) are listed so you can pick a winner.
📊 SPEC COMPLETENESS AUDIT — find robots with thin data
Scores each robot against three tiers: Critical (8 fields every robot needs: brand, name, category, year, country, image, score, description), Standard (10 fields most robots should have: price, dimensions, weight, battery, speed, status, capability, connectivity, tags), and Optional (the long tail). Realistic targets: 100% critical, 70-80% standard, 30-50% optional. Click any robot to research missing fields via the Command Centre.
⚡ Bulk fill tools (uses Anthropic API)
Phase 1: Fill missing year + origin (country) only — ~$0.005/robot, batches of 10.
Phase 2: Full re-ingestion of thin records (Standard < 50%) — ~$0.10/robot, one at a time.
Both save locally as they go. Click 💾 Save + Deploy when finished to push to live site.
🗂️ CATEGORY NORMALIZER — collapse AI-invented categories into canonical 19
Phase 2 ingestion let the AI invent categories like "Robot Vacuum & Mop" and "6-Axis Industrial Robot" instead of using your 19 canonical categories. As a result, hundreds of robots are invisible to the public site's category filter. This tool maps every non-canonical category to its best canonical match (sets cat) and preserves the original AI category as sub for future hierarchical filtering.
🏷️ SUB-CATEGORY NORMALIZER — collapse AI-invented sub-types into canonical sub-types per category
The sub-category filter on the public site is cluttered with duplicates like "Robot Vacuum & Mop" / "Vacuum + Mop" / "Robot Vacuum and Mop" — all the same thing. This tool maps every AI variation to a clean canonical sub-type within each main category. The result: 5-8 useful sub-types per category instead of 20-40 fragments. Does NOT touch last_verified — renaming isn't verifying.
