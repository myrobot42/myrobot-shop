EpicSim

Applied Intuition · Autonomous Vehicles · 2023

Applied Intuition's EpicSim is a high-fidelity simulation and validation environment for developing autonomous-vehicle software. It generates photorealistic sensor data (camera, lidar, radar) and large-scale scenario libraries so developers can test and validate self-driving stacks in software across billions of virtual miles before on-road deployment.
