Bittle X

Petoi · Quadruped · 2023

An open-source, palm-sized programmable robot dog built on Petoi's OpenCat framework. Powered by an ESP32 controller with 9 servo-driven joints, it walks, trots and does tricks, and is programmable via block-based coding, Arduino/C++ or a Python API. A Raspberry Pi can be mounted for advanced AI and vision projects.
